# MORDO® — Landing de pedidos

Landing de MORDO® (hamburguesas al carbón, Cartagena). La página es estática (`index.html`); `server.js` la sirve en Railway con Node, sin dependencias.

- Local: `npm start` → http://localhost:3000
- Salud: `/health`
- WhatsApp de pedidos: cambiar la constante `WHATSAPP` en `index.html` (hoy `573000000000`, de prueba).
